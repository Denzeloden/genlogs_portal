# Initial Portal — Proposal

## Why
Build the GenLogs web portal prototype per the technical assessment: users search origin/destination cities, view top 3 routes on Google Maps, and see carriers ranked by daily truck volume.

## Scope
- React SPA with search form, route maps, carrier list
- FastAPI backend with PostgreSQL-seeded mock data
- Heroku single-dyno deployment with Postgres addon
- Open Spec SDD artifacts and reference documentation

## Out of Scope
- Live Trident sensor ingestion
- Vision AI processing
- Live SAFER FMCSA API integration
